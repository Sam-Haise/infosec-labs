# 🛰️ Раздел 01 — Zeek / Network Security Monitoring

Восемь работ по системе обнаружения вторжений **Zeek**: от запуска и чтения
журналов до написания собственных сигнатур и скриптов для детектирования атак.
Это ядро blue-team-навыка — превращать сырой сетевой трафик в события
безопасности.

**Стенд:** виртуальная машина `Zeek_Master`, генерация трафика в **Mininet**,
готовые файлы захвата (`.pcap`).
**Инструменты:** Zeek, ZeekControl, `zeek-cut`, Linux-утилиты (`sort`, `uniq`,
`head`), AWK, Nmap, tcpdump, LOIC.

## Что демонстрирует раздел

- Полный цикл работы аналитика NSM: **захват → логи → выборка → вывод**.
- Умение видеть атаку в трафике: brute-force, сканирование портов, DoS.
- Навык не только пользоваться готовыми правилами, но и **писать свои**
  сигнатуры и скрипты на языке Zeek.
- Уверенная работа в терминале Linux: конвейеры `zeek-cut | sort | uniq | awk`.

> 🎓 Учебные работы. Весь трафик сгенерирован в изолированной среде Mininet или
> взят из учебных `.pcap`-файлов.
