# 🛡️ infosec-labs — портфолио по информационной безопасности

Практические работы по сетевой безопасности: обнаружение вторжений, защита
сетевой инфраструктуры и аудит беспроводных сетей. Всё выполнено собственноручно
на изолированных стендах и подконтрольном оборудовании, с полным разбором,
командами и выводами.

> **Автор:** Сэм · направление «Информационная безопасность автоматизированных систем»
> **Цель:** junior SOC-аналитик / специалист по защите информации

## Чему научили эти работы

**🔵 Blue team — обнаружение и защита (основной фокус)**

- Развернуть и обслуживать **Zeek** как систему обнаружения вторжений (NSM),
  читать и парсить журналы (`conn.log`, `http.log`, `signatures.log`) связкой
  `zeek-cut` + `sort`/`uniq`/`awk`.
- Обнаруживать по трафику **сканирование портов** (SYN/FIN/XMAS/NULL) и
  **DoS-атаки** (SYN-flood, UDP-flood), находить IP атакующего и целевые порты
  по логам.
- Писать **сигнатуры** и **скрипты Zeek** для автоматического выявления заданных
  событий и аномалий.
- Настраивать защиту коммутатора Cisco: **Port Security**, **Dynamic ARP
  Inspection**, защита таблицы CAM и противодействие подмене DHCP.
- Разбирать пакеты в **Wireshark**: видеть, что HTTP и Telnet передают учётные
  данные открытым текстом, а HTTPS/SSH — нет.

**🔴 Red team — насколько нужно, чтобы защищаться грамотно**

- Разведка сети через **Nmap** (типы сканирования, определение ОС и сервисов).
- Эксплуатация уязвимого сервера (**Metasploit / Armitage**, Metasploitable 2):
  vsftpd backdoor, Samba usermap, слабые учётки, устаревшие сервисы — и меры
  по устранению каждой уязвимости.
- Аудит **Wi-Fi**: перехват WPA2-рукопожатия, Evil Twin + captive portal, PMKID —
  с честными выводами о том, где защита реально работает.

## Как это читать

Каждый раздел — отдельная папка с собственным `README.md`, где по каждой работе:
цель, стенд, ход, результат и **вывод по безопасности** (что это значит для
защиты). Полные отчёты со скриншотами лежат в подпапке `reports/`.

```
infosec-labs/
├── 01-zeek-nsm/           # NSM / IDS на Zeek
│   ├── README.md
│   └── reports/           # 8 отчётов .docx
├── 02-network-defense/    # Cisco / EVE-NG
│   ├── README.md
│   └── reports/           # 8 отчётов .docx
└── 03-wifi-security/      # Аудит Wi-Fi
    └── README.md
```

## ⚖️ Дисклеймер

Все материалы носят **учебный и исследовательский характер** и предназначены для
изучения методов защиты. Работы выполнены:

- в **изолированных виртуальных стендах** (VirtualBox, EVE-NG, Mininet) либо
- на **собственном оборудовании** автора.

Никакие атаки не проводились против чужих систем и сетей. Идентификаторы реальной
домашней сети в разделе Wi-Fi **обезличены**. Применение описанных техник против
чужой инфраструктуры без письменного разрешения владельца незаконно
(в РФ — ст. 272–274 УК РФ).
